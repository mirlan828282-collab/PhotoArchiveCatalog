# Фотокаталог

Локальная база фотографий для Windows 7/10/11. Данные хранятся на компьютере пользователя в SQLite; фотографии копируются в локальное хранилище программы.

## Возможности

- карточка каждой фотографии: архивный номер, описание, дата съёмки, место, автор, источник поступления;
- миниатюры фотографий прямо в списке;
- обычный поиск по всем текстовым полям;
- массовый импорт фотографий с автоматической нумерацией;
- импорт `.xlsx` и `.csv`;
- импорт `.mdb/.accdb` через установленный Microsoft Access Database Engine / ODBC Driver;
- резервная копия всей базы и фотографий в ZIP и восстановление из неё;
- локальный поиск похожих лиц по фотографии;
- GitHub Actions автоматически собирает `PhotoArchiveCatalog.exe`.

## Поиск по лицу

Используются локальные модели OpenCV Zoo: YuNet для обнаружения лица и SFace для формирования признаков лица. Фотографии не отправляются в интернет. Перед первым поиском выполните **Лица → Индексировать лица**.

## Импорт Excel / CSV

Первая строка должна содержать названия столбцов. Программа понимает русские заголовки:

- `Архивный номер`
- `Описание фотографии` или `Описание`
- `Дата съёмки`
- `Место съёмки`
- `Автор съёмки`
- `Источник поступления`
- `Фото` / `Фотография` / `Путь к фото`

Путь к фотографии может быть абсолютным или относительным к папке Excel/CSV-файла.

## Локальный запуск

Для старого Windows 7 рекомендуется Python 3.8.10 x64.

```bat
run.bat
```

## Сборка EXE локально

```bat
build_windows.bat
```

Готовый файл: `dist\PhotoArchiveCatalog.exe`.

## Сборка через GitHub

1. Создайте пустой репозиторий GitHub.
2. Загрузите **всё содержимое этой папки**, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**.
4. Выберите **Build Windows EXE**.
5. Нажмите **Run workflow**.
6. После завершения откройте запуск и скачайте артефакт **PhotoArchiveCatalog-Windows**.

Workflow также запускается автоматически при `push` в ветку `main` или `master`.

## Где хранятся данные

У EXE-версии:

`%LOCALAPPDATA%\PhotoArchiveCatalog`

Внутри находятся:

- `catalog.db` — база SQLite;
- `photos\` — оригиналы фотографий;
- `thumbs\` — миниатюры.

Перед крупным импортом рекомендуется создать резервную копию через меню **Файл → Создать резервную копию**.
