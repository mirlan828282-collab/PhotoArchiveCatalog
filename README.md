# PhotoArchiveCatalog v3

Локальный фотокаталог для Windows: три режима (просмотр, редактирование, каталог), импорт Access/Excel/CSV/Word, массовая привязка фотографий по архивным номерам, резервное копирование и локальный поиск по лицу YuNet + SFace.

Пароль защищённых разделов по умолчанию: `12345`.

## GitHub Actions
Откройте **Actions → Build Windows EXE → Run workflow**. После успешной сборки скачайте artifact `PhotoArchiveCatalog-Windows`.
