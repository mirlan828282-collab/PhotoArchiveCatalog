ФОТОКАТАЛОГ — Архив Президента Кыргызской Республики
Версия 3

Главные режимы:
1. Просмотр и поиск — только чтение. Поиск по целому слову включён по умолчанию.
2. Редактирование — добавление, исправление и удаление карточек, импорт данных и фото.
3. Каталог — общий список с миниатюрами, полосами прокрутки, увеличением при наведении и открытием фото.

Пароль по умолчанию для перехода в защищённые режимы: 12345

ИМПОРТ ДАННЫХ
Поддерживаются:
- Microsoft Access: MDB, ACCDB (нужен Microsoft Access Database Engine / ODBC той же разрядности, что и программа)
- Excel: XLSX, XLSM
- CSV
- Word: DOCX, если данные находятся в таблице

Распознаются типовые названия столбцов: Архивный номер, Арх. №, Содержание, Описание, Дата съемки, Место съемки, Автор/Фотограф, Источник поступления, Фото/Файл и др.
Если архивный номер уже есть, метаданные обновляются, а непустое существующее фото не стирается пустым значением.

МАССОВЫЙ ИМПОРТ ФОТО ПО АРХИВНОМУ НОМЕРУ
1. Сначала импортируйте список из Access/Excel/Word.
2. Назовите файлы фотографий по архивным номерам. Примеры:
   Ф-001245.jpg
   Ф-001245_1.jpg
   Ф-001245 (2).tif
3. В режиме редактирования нажмите «Импорт фото по архивным №» и выберите папку.
Программа привяжет фото к записи с тем же архивным номером. Если к номеру относится несколько файлов, создаются дополнительные карточки с теми же описательными данными.

ПОИСК ПО ЛИЦУ
В режиме редактирования выполните «Индексировать лица». Программа индексирует все найденные лица на каждой фотографии. После этого поиск по лицу доступен в первом окне.
